# Навчальний проєкт: React, TypeScript та Axios

Невеликий навчальний застосунок на React і TypeScript, який під час відкриття сторінки отримує публікації з відкритого API та показує їх у вигляді адаптивних карток. Приклад демонструє повний цикл асинхронного запиту: завантаження, успішне отримання даних і обробку помилки.

## Мета

Практично розібратися, як:

- створити React-проєкт за допомогою Vite та шаблону TypeScript;
- використовувати `useEffect` для запуску запиту після першого рендеру компонента;
- виконувати HTTP-запит за допомогою Axios та `async/await`;
- описувати форму відповіді сервера через інтерфейс TypeScript;
- зберігати дані й стан запиту у `useState`;
- умовно показувати повідомлення про завантаження, результат або помилку;
- відображати масив даних у React через `map()` та ключі `key`.

## Технології

- React 19
- TypeScript
- Vite
- Axios
- Oxlint

## Вимоги

Перед запуском установіть Node.js та npm. Для отримання публікацій потрібне підключення до інтернету.

## Встановлення та запуск

Відкрийте термінал у каталозі проєкту й виконайте:

```bash
npm install
npm run dev
```

Vite виведе адресу локального сервера в терміналі. Відкрийте її у браузері.

### Інші команди

```bash
npm run build    # Перевірити TypeScript і створити production-збірку в dist/
npm run preview  # Переглянути production-збірку локально
npm run lint     # Запустити Oxlint
```

## Як працює запит

Компонент `DataFetcher` у `src/components/DataFetcher.tsx` виконує GET-запит до JSONPlaceholder:

```text
https://jsonplaceholder.typicode.com/posts?_limit=6
```

У відповіді надходить масив публікацій із полями `userId`, `id`, `title` і `body`. Інтерфейс `Post` типізує ці дані. Запит запускається всередині `useEffect`, а `AbortController` скасовує його, якщо компонент буде демонтовано до завершення запиту.

Компонент керує трьома станами:

1. **Завантаження** — показується повідомлення «Завантаження даних із сервера...».
2. **Успіх** — отримані публікації відображаються у картках.
3. **Помилка** — показується повідомлення, якщо запит не вдався.

## Структура проєкту

```text
my-react-app/
├── public/                 # Статичні файли
├── src/
│   ├── assets/              # Зображення та інші ресурси
│   ├── components/
│   │   └── DataFetcher.tsx  # Запит, стани й відображення публікацій
│   ├── App.tsx              # Основний компонент сторінки
│   ├── App.css              # Стилі інтерфейсу та карток
│   ├── index.css            # Глобальні стилі
│   └── main.tsx             # Точка входу React-застосунку
├── package.json             # Залежності та npm-команди
└── vite.config.ts           # Конфігурація Vite
```

## Що можна змінити для практики

- Показати іншу кількість публікацій, змінивши параметр `_limit` в URL.
- Звернутися до іншого ресурсу JSONPlaceholder, наприклад `/users` або `/comments`.
- Додати кнопку повторного завантаження та відповідний обробник події.
- Вивести додаткові поля з відповіді API.
- Змінити стилі карток у `src/App.css`.
